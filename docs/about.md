# About Pre-

Pre- is designed to be a comprehensible starting point for any Design System.[^1]

Its abstractions are heavily influenced by a confluence of different methods such as Atomic Design[^2], frontend programming, grid systems[^3] among few other matured strategies. However after many years experiencing different approaches it is clear that there’s no on solution fits all. There will always be constrains, trade-offs that  will not work as intended. In those cases adaptation should be freely encouraged. 

[^1]: [Design System on Wikipedia](https://en.wikipedia.org/wiki/Design_system)
[^2]: [Atomic Design](https://bradfrost.com/blog/post/atomic-web-design/)
[^3]: [Grid Systems](https://en.wikipedia.org/wiki/Josef_Müller-Brockmann) by Josef Müller-Brockmann
